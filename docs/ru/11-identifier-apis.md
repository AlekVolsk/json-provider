# API идентификаторов

Два O(1)-чтения `meta.json`:

```php
$last = $db->table('products')->getLastInsertedId();   // 0, если вставок не было
$next = $db->table('products')->getNextId();           // last + 1
```

`getLastInsertedId()` — последний выданный id для таблицы. После удаления **не** откатывается — id никогда не переиспользуются (тот же контракт, что у SQL `AUTO_INCREMENT`).

`getNextId()` — предсказание следующего id, но **не резервирование**. Параллельный insert может «съесть» это значение, текущий вызов получит `last + 2`. Используйте для имён файлов или токенов, которые формируются **до** вставки; если нужно строгое резервирование — выполняйте insert сразу.
