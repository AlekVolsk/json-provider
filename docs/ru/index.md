# JsonProvider — руководство

**Важная ремарка!** эта документация была составлена AI-инструментом на основе кодовой базы. Пожалуйста, относитесь к описанию здесь с осторожностю! Любые переводы документации также являются AI-переводом, если не было вмешательства сообщества.

JsonProvider — это самодостаточный PHP-провайдер данных, работающий с каталогом NDJSON-файлов как с небольшой реляционной базой.

Этот документ — рабочий справочник для инженера, встраивающего JsonProvider в PHP-проект. Здесь описаны контракты, публичные API, ожидаемое поведение и операционные темы. Внутренняя механика затрагивается только там, где это нужно для понимания внешнего поведения.

> Экспериментальная заметка: этот провайдер был разработан end-to-end через Claude Code под человеческим руководством, в рамках эксперимента по созданию рабочего программного модуля исключительно средствами AI.
